# باتش تحديث النسخة العربية

هذا الباتش يحدّث النسخ السابقة من اللعبة المعربة إلى أحدث نسخة.

## التشغيل

1. أغلق اللعبة إن كانت تعمل.
2. فك ضغط ملف الباتش في أي مجلد.
3. شغّل **`update.bat`** مرة واحدة.
4. إذا طُلب مسار اللعبة، ألصق مسار المجلد الذي يحتوي `Doki Doki Literature Club Plus.exe`.

سينسخ الباتش الملفات الأصلية إلى مجلد احتياطي قبل التحديث.
